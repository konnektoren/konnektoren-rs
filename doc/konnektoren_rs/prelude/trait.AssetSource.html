Expand description

Delivers raw bytes for a path — the only async piece of the pipeline.

Implementations decide where bytes come from: compile-time embeds (EmbeddedSource), the filesystem (FileSource), HTTP fetch ([UrlSource], CSR), or — in richer implementation crates — zip archives and source chains. Callers never branch on the backend; they pick which source value to construct (or get one injected) and the call shape stays the same.

The trait is async by contract because real backends must await (browser fetch, filesystem reads); instant backends like EmbeddedSource simply resolve immediately. The returned futures are not required to be Send so that wasm-only backends can implement this trait.
